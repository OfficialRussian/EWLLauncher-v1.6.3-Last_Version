# EWLLauncher

Лаунчер **Minecraft Java Edition** для Windows. Скачивает и запускает версии игры, ставит Fabric, Quilt, Forge и NeoForge, ускоряет игру модами производительности и позволяет подключиться к серверу друга **напрямую, без прокси и VPN**.

> Не является официальным продуктом Mojang Studios или Microsoft. Minecraft — торговая марка Mojang Studios. Для игры с лицензионным сервером нужна купленная копия Minecraft: Java Edition.

## Возможности

- **Версии:** релизы, снапшоты и старые версии Minecraft, загрузка с официальных серверов Mojang с проверкой SHA-1; нужная Java подтягивается автоматически.
- **Загрузчики:** Vanilla, Fabric, Quilt, Forge (от 1.12.2) и NeoForge (от 1.20.2) через официальные установщики. К Fabric и Quilt сразу ставится нужная библиотека (Fabric API / Quilted Fabric API). У каждого профиля с загрузчиком своя папка (`instances/<профиль>`) со своими модами, мирами и настройками.
- **Маркет модов:** поиск на Modrinth по версии и загрузчику выбранной сборки, установка в её папку `mods` вместе с обязательными зависимостями, список и удаление установленных модов.
- **Скины:** встроенный редактор скина 64×64 (кисть, заливка, пипетка, отмена), превью со всех сторон, библиотека, импорт/экспорт PNG, загрузка скина в аккаунт Microsoft.
- **Сборки:** переименование (отображаемое имя) и удаление с подтверждением, по желанию вместе с папкой профиля (миры, моды, настройки).
- **Разбор вылетов:** после падения игры лаунчер читает лог, crash-report и hs_err и объясняет причину (версия Java, память, дубликаты и зависимости модов, Mixin-конфликты, драйвер видеокарты, повреждённые файлы и др.) с шагами решения.
- **Приветствие и файлы:** анимация «Добро пожаловать!» с именем игрока при входе, окно «Файлы лаунчера» с быстрым открытием папок.
- **Оптимизация:** по предложению при запуске ставит с Modrinth моды производительности (Sodium, Lithium, FerriteCore, ImmediatelyFast, Entity Culling, ModernFix) вместе с зависимостями. Чужие моды не трогает.
- **Аккаунты:** офлайн-ник и вход через Microsoft (Device Code, пароль лаунчеру не передаётся). Токены хранятся зашифрованно (Windows DPAPI).
- **Настройки:** оперативная память, путь к Java, папка игры, размер окна, дополнительные аргументы JVM, акцентный цвет интерфейса.
- **Игра с другом:** хозяин создаёт подключение одной кнопкой и получает код приглашения, друг вставляет код, лаунчер проверяет сервер, ставит нужную версию и сам заходит на сервер.

## Как работает подключение к другу

Прямое TCP-соединение игрок↔игрок, без посредников:

1. Лаунчер проверяет, что сервер запущен (Server List Ping).
2. Определяет внешний IPv4 (STUN) и открывает порт на роутере через **UPnP**; доступен также ручной проброс порта.
3. Добавляет глобальный **IPv6**, если он есть, и предупреждает о «сером» IP провайдера (CGNAT).
4. Выдаёт код `EWL1-…` со сроком действия и контрольной суммой. В коде нет паролей и токенов, вход защищают белый список и online-mode сервера.

Прямое соединение возможно не всегда: если у хозяина нет белого IPv4 и IPv6, а на роутере нет UPnP и порт не проброшен вручную, подключиться без посредника нельзя. Кнопка «Проверить сеть» показывает, что именно мешает.

## Установка и сборка

Нужны Windows и [Node.js LTS](https://nodejs.org). Сначала **распакуйте архив** («Извлечь всё…»), затем запускайте `BUILD.bat` из распакованной папки: из самого архива он не работает.

```bat
BUILD.bat
```

Скрипт установит зависимости, создаст иконку, прогонит тесты и соберёт в папке `dist`:

- `EWLLauncher-Portable-<версия>.exe` — запускается без установки;
- `EWLLauncher-Setup-<версия>.exe` — установщик.

Запуск для разработки: `RUN-DEV.bat` (или `npm install && npm run dev`). Тесты: `npm test`.

Windows SmartScreen может предупредить о неподписанном приложении: «Подробнее → Выполнить в любом случае».

## Вход через Microsoft

Microsoft требует зарегистрированное приложение. Один раз, бесплатно:

1. Azure Portal → «Регистрация приложений» → «Новая регистрация».
2. Типы учётных записей: только личные учётные записи Майкрософт.
3. «Проверка подлинности» → «Разрешить публичные клиентские потоки» = Да.
4. Скопируйте «Идентификатор приложения (клиент)» в «Настройки → Azure Client ID».
5. Запросите доступ к API Minecraft: https://aka.ms/AppRegInfo (без этого Mojang отвечает ошибкой 403).

Офлайн-режим работает без регистрации.

## Ограничения

- Только Windows (сборка и пути рассчитаны на неё).
- Загрузчики ставятся официальными установщиками Forge и NeoForge, первая установка занимает несколько минут.
- Маркет модов работает с Modrinth. CurseForge требует личный API-ключ, поэтому пока не подключён.
- Скин на сервере виден только у аккаунтов Microsoft: у офлайн-аккаунтов нет профиля Mojang.
- Моды производительности (оптимизация) ставятся только на профили Fabric и Quilt, а через «Маркет модов» можно ставить любые моды в профили всех четырёх загрузчиков; для самых новых версий Minecraft подходящих модов может ещё не быть.
- Нет автообновления лаунчера и подписи кода.

## English summary

**EWLLauncher** is a Windows launcher for Minecraft Java Edition (Electron). It installs Vanilla, Fabric, Quilt, Forge and NeoForge profiles (with Fabric API), has a Modrinth mod market, a built-in skin editor, crash diagnosis from game logs, with SHA-1 verification, offers one-click performance mods from Modrinth, supports offline and Microsoft accounts (device code flow, tokens encrypted with DPAPI), and lets two players connect directly without a proxy or VPN (UPnP port mapping, public IPv4/IPv6, invite codes). Build with `BUILD.bat` (Node.js LTS required). Not affiliated with Mojang or Microsoft.

## Новое в 1.4
- **Управление сборкой** (Версии → «Управление»): переименование, своя память и JVM-аргументы, бэкапы миров, копия, экспорт в `.zip`, папка сборки.
- **Импорт сборки** из `.zip` (кнопка под списком установленных версий). Для Forge/NeoForge нужная версия загрузчика должна быть установлена заранее.
- Бэкапы лежат в `<папка игры>\backups\<сборка>\`.

## Новое в 1.5
- **Маркет:** вкладки «Модпаки» (установка .mrpack с Modrinth как новой сборки), «Ресурспаки и шейдеры», кнопка «Проверить обновления» на вкладке «Установлено в сборке» (прошлые версии сохраняются в `mods-backup`, есть «Откатить»).
- **Серверы:** избранные серверы, онлайн/пинг/MOTD, запуск игры сразу на сервер.
- **Статистика:** время в игре по сборкам и галерея скриншотов.
- **Темы:** тёмная, «Полночь», AMOLED, светлая (Настройки → Внешний вид).
- **Обновления лаунчера:** при запуске проверяется последний релиз GitHub-репозитория из настроек (`updateRepo`, по умолчанию OfficialRussian/serfgg). Чтобы уведомление сработало, опубликуйте на GitHub релиз с тегом вида `v1.5.0`.

## Новое в 1.6
- **CurseForge** в маркете модов. Ключ API вводится в Настройки → CurseForge и хранится только на вашем компьютере (в код и в репозиторий он не попадает). Скачиваются только моды, которые автор разрешил раздавать вне сайта CurseForge; остальные пропускаются с пояснением. Обновление модов пока работает только для Modrinth.
- **Discord-статус:** «Играет в Minecraft» с названием сборки и временем игры. Выключается в Настройки → Внешний вид. Нужен запущенный Discord на этом же компьютере.

## 1.6.1 — производительность
