# EWLLauncher-v1.6.3-Last_Version
EWLLauncher — простой лаунчер Minecraft Java для Windows: введи ник и играй. Fabric, Quilt, Forge и NeoForge, маркет модов (Modrinth, CurseForge), модпаки, редактор скинов, бэкапы миров, разбор вылетов. Игра с друзьями напрямую, без прокси и VPN. Офлайн и Microsoft-вход.
